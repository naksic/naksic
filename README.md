# Hi, I'm Nikola

I study Information Systems and Technologies at the Faculty of Organizational Sciences (FON), University of Belgrade, where my main interests are data science, machine learning, full-stack web development, and UML modeling. I like writing clean code that is easy for others to read, understand, and build on.

Principles I try to follow in my code:

* **Readable** - Descriptive names and a clear structure, so the code largely explains itself
* **Maintainable** - Small, focused components that are easy to change and reuse
* **Well-Designed** - Careful analysis and modeling of the problem before any implementation

## Areas of Interest

* **Data Science** - Cleaning, visualizing, and processing data
* **Machine Learning** - Exploring how different algorithms work and where they fit best
* **Full-Stack Development** - Building complete web applications, from the database to the user interface
* **UML Modeling** - Analyzing and describing a wide range of problems through diagrams
